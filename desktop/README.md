## instrucciones para crear el ejecutable portable windows.

1. npm install

2. npm run pack

Esto generara nuevas carpetas, en la llamada "release" se guardan los datos y el archivo ejecutable del sistema. 

.\SistemaApoyoInspectoria\desktop\release\win-unpacked\Apoyo Inspectoria.exe


2.1. npm run dist

El comando anterior genera una version totalmente portable del sistema pero demora mas en abrir.
